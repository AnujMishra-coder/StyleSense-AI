# StyleSense AI – Fashion Review Analytics

**NLP | Machine Learning | Text Classification | Clustering | Topic Modeling**

StyleSense AI analyzes customer feedback from the Women's E-Commerce Clothing Reviews dataset using natural language processing and machine learning.

This repository is an independently maintained extension of an earlier academic group project. Preserve the original contributors' attribution and any applicable license when publishing or distributing the work.

## Features

- Text cleaning and preprocessing using NLTK
- TF-IDF and Bag-of-Words feature extraction
- Recommendation classification using Multinomial Naive Bayes, LinearSVC and KNN
- Cross-validation and held-out test-set evaluation
- K-Means review clustering
- LDA topic modeling
- Streamlit dashboard with Overview, Review Analyzer, ML Insights and Topic Explorer pages

## Dataset

Download the **Women's E-Commerce Clothing Reviews** dataset from Kaggle:

https://www.kaggle.com/datasets/nicapotato/womens-ecommerce-clothing-reviews

Place the CSV in the project root and name it:

`Womens Clothing E-Commerce Reviews.csv`

The raw dataset is not included in this repository.

## Setup

Python 3.10–3.12 is recommended for broad compatibility with the scientific Python packages.

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Run the complete ML pipeline:

```bash
python src/main.py
```

This generates processed data, sparse matrices, evaluation outputs and saved models under `outputs/` and `models/`.

Start the Streamlit dashboard:

```bash
streamlit run app.py
```

You can also run individual stages:

```bash
python src/numerical.py
python src/classification.py
python src/clustering.py
python src/topic_modeling.py
```

## Important notes

- The first preprocessing run downloads the required NLTK resources.
- Classification is evaluated using a stratified train/test split and cross-validation.
- Clustering is run on a reproducible sample to reduce runtime and memory use.
- The dashboard's review prediction requires the saved TF-IDF vectorizer and trained classifier pipeline generated by the pipeline.
- Model scores are generated locally from the dataset; no performance figures are hardcoded in the README.
- Do not commit raw data, virtual environments, secrets, or large generated model files unless you have checked the dataset terms and repository limits.
